# Рассылка студиям Тюмени — партнёрский оффер (white-label + комиссия)

Под список `workspace-tyumen-developers.csv`. Цепочка из 3 писем в одном треде (Re:).
Поля `{{...}}` — подстановка. 20–30 писем/день с прогретого домена, утро вт–чт.

Мердж-поля из CSV: `{{Имя}}` (контактное лицо), `{{Студия}}` (название), `{{сайт}}` (website).

## Письмо 1 — заход (день 0)

**Тема (тест A/B, без капса и спам-слов):**
- A: `Чат для ваших клиентов — под брендом {{Студия}}`
- B: `{{Имя}}, вопрос по чатам, которые ставите клиентам`

> Здравствуйте, {{Имя}}!
>
> Вы в Тюмени делаете сайты под ключ — и наверняка ставите клиентам онлайн-чат, чаще всего Jivo. Клиент за него платит каждый месяц, а студия с этого не получает ничего.
>
> Мы сделали Lemnity — российский чат-виджет (в реестре отечественного ПО, данные в РФ). Для студий есть **white-label**: ставите клиентам под своим брендом и получаете **повторяющуюся комиссию** с каждого. Перенос с Jivo и настройку берём на себя.
>
> 60 секунд, как это выглядит: {{ссылка на демо}}
>
> Дам партнёрский доступ — поставите на один проект, без обязательств. Скинуть?
>
> {{Имя_отправителя}}, Lemnity · hello@lemnity.ru

**Психология в письме 1:**
- *Unity / Liking* — «Вы в Тюмени делаете сайты под ключ»: сигнал «это не массовый спам, письмо вам», свой к своему.
- *Loss aversion / Framing* — «клиент платит, а студия не получает ничего»: открываем боль упущенной выгоды (потеря ощущается сильнее, чем выгода).
- *Authority* — «реестр ПО, данные в РФ»: снимает риск и закрывает импортозамещение.
- *Reciprocity* — «перенос и настройку берём на себя» + бесплатный доступ: даём первыми.
- *Foot-in-the-door + снятие риска* — «на один проект, без обязательств»: микро-шаг, легко сказать «да».
- *Hick's Law / низкое трение* — одна мысль, одна ссылка, CTA = «скинуть?» (ответ в одно слово).

## Письмо 2 — польза + снятие возражений (день +3, тот же тред)

**Тема:** `Re: Чат для ваших клиентов — под брендом {{Студия}}`

> {{Имя}}, добавлю по сути — почему студии переходят с Jivo на нас:
>
> • **Белый лейбл** — клиент видит ваш бренд, не наш.
> • **Комиссия {{20–30%}}** с каждого клиента, ежемесячно, пока он пользуется.
> • **Реестр РФ + данные в РФ** — закрывает импортозамещение, многим заказчикам это уже принципиально.
> • Помимо чата — обратный звонок, видео-виджет, «Колесо фортуны», таймеры: есть что допродать клиенту.
>
> Работы вам не добавляется — перенос и настройку делаем мы. Дать доступ на один проект?
>
> {{Имя_отправителя}}, Lemnity

**Психология в письме 2:**
- *Paradox of choice → буллеты* — 4 коротких пункта вместо абзаца, легко просканировать.
- *Recurring value / якорь* — «ежемесячно, пока пользуется»: подчёркиваем повторяемость дохода.
- *Bandwagon (social proof)* — «почему студии переходят»: другие уже делают это.
- *Upsell-крючок* — допродажи клиенту: показываем, что партнёрство = дополнительный заработок, а не просто замена Jivo.
- *Status-quo bias снимаем* — «работы вам не добавляется»: убираем главный страх «это лишняя возня».

## Письмо 3 — мягкое закрытие (день +7, тот же тред)

**Тема:** `Re: Чат для ваших клиентов — под брендом {{Студия}}`

>
> Партнёрские условия на одной странице: {{ссылка}}
>
> {{Имя_отправителя}}, Lemnity · @lemnity_ru

**Психология в письме 3:**
- *Regret aversion / снятие риска* — «терять нечего», «не понравится — отключим»: убираем страх ошибки.
- *Pratfall / честность* — «закрываю, чтобы не надоедать»: располагает, снижает давление.
- *Лёгкий выход* — «ответьте "не актуально"»: парадоксально повышает реплай-рейт (дать лёгкий «нет» проще, чем игнор).

## Памятка по запуску
- **Реплай-рейт, а не открытия.** Цель B2B-цепочки — 5–10% ответов. Ниже 3% → меняем оффер/тему, не объём.
- **Картинки в тело первого письма не вставлять** — режет доставляемость. Демо — ссылкой.
- **Фоллоу-ап в том же треде** (Re:), не новой темой.
- **Перед отправкой** проверь по CSV колонку «Заметка»: пропусти мёртвые домены (ИнфоСистем закрыта, P6/ИП Губкин — домен мёртв, ArtSky — под вопросом). Для строк «email не публикуется / нет сайта» — это письмо не годится, иди в VK/Telegram (колонка Social).
