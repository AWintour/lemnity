# Lemnity cold-mailer — Google Apps Script

Рассылка цепочек с рабочей почты прямо из Google Таблицы. Управление — кнопками
в меню «📧 Lemnity», без редактора скриптов.

## Установка (один раз, ~5 минут)

1. Создайте новую Google Таблицу.
2. Сверху: **Extensions → Apps Script**. Откроется редактор.
3. Сотрите весь текст в окне и вставьте туда [Code.gs](Code.gs). Нажмите 💾 (сохранить).
4. Вверху файла, в блоке `CONFIG`, поменяйте 3 строки под себя:
   - `SENDER_ALIAS` — адрес, с которого шлёте (или оставьте `''` = основной).
   - `DEMO_LINK` и `PARTNER_LINK` — ваши ссылки.
5. Вернитесь в Таблицу и **обновите страницу** (F5). Появится меню **📧 Lemnity**.

## Дальше — только меню в Таблице

**📧 Lemnity → 1. Создать/проверить лист**
Google один раз попросит разрешения (Gmail + Таблицы) — нажмите Allow.
Создастся лист `Contacts` с готовой шапкой.

**Заполните лист.** Нужны всего 3 столбца, остальное скрипт ведёт сам:

| Email | Company | Website |
|-------|---------|---------|
| info@dotimo.ru | Dotimo | https://dotimo.ru |

> Скопировать из вашего CSV: откройте его в Excel/Google Sheets, выделите нужные
> 3 колонки, вставьте под шапку. Имя/город можно не заполнять.

**📧 Lemnity → 2. Запустить сейчас (тест)**
Отправит первые письма (до 25 за раз). Проверьте папку «Отправленные» в Gmail.

**📧 Lemnity → 3. Включить автопилот**
Дальше всё само: вт/ср/чт в 10:00 скрипт шлёт письмо 1 новым, письмо 2 — через
3 дня, письмо 3 — через 7 дней, всё одним тредом. Кто ответил — выпадает из
рассылки автоматически.

Выключить: **📧 Lemnity → Выключить автопилот**.

## Если что-то не так
- Меню не появилось → обновите страницу таблицы (F5).
- Хотите остановить кого-то вручную → в листе `Contacts`, столбец `Status`,
  впишите `replied`.
- Логи прогона → в редакторе Apps Script: **View → Logs**.

## Лимиты
Consumer Gmail ~100 писем/день, Workspace ~1500. Для доставляемости держите
20–30/день (`DAILY_LIMIT` в CONFIG) и прогревайте домен постепенно.
