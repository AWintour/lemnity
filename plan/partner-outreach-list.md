# Lemnity — список под партнёрский outreach

Цель: собрать **100–200 веб-студий / агентств / сайтоделов**, которые уже ставят клиентам чаты, и выйти на них с партнёрским оффером (white-label + комиссия). Один партнёр = много установок.

---

## 1. Кого ищем (профиль идеального партнёра)

- Делает сайты **под ключ** или на конструкторах (Tilda, WordPress, InSales, Bitrix, Webflow).
- Ставит клиентам онлайн-чат / Jivo / формы заявок (значит, виджеты — часть их работы).
- Малые/средние студии и фрилансеры — им важна комиссия и white-label, решение принимает 1 человек (быстро).
- Бонус: позиционируется на «российское/импортозамещение» — наш угол реестра РФ им в тему.

**Кого пропускать:** крупные сетевые агентства (долгий цикл, не до вас на старте), компании без сайтов клиентов (SMM-only).

---

## 2. Где брать (источники, по приоритету)

1. **Каталоги Tilda-экспертов / сертифицированных партнёров** — там прямо сидят те, кто делает сайты и ставит виджеты.
2. **Маркетплейсы/каталоги веб-студий:** рейтинги студий по городам, агрегаторы «заказать сайт».
3. **VK-сообщества веб-студий и фрилансеров** (Tilda, WordPress, верстка, «сделаю сайт») — оттуда же работает ваш парсер активной аудитории.
4. **Telegram-чаты** по Tilda / фрилансу / веб-разработке — участники и админы.
5. **Поисковая выдача:** `заказать сайт {{город}}`, `веб-студия {{город}}`, `сайт на Tilda под ключ` — первые 3–5 страниц по 20–30 городам.
6. **Сайты, где уже стоит Jivo/чат:** студии часто ставят свой виджет на собственный сайт — а в подвале пишут «сделано в {{студия}}». Это тёплые контакты.
7. **Биржи фриланса** — исполнители с услугой «сайт + настройка чата».

## 3. Что собирать (поля таблицы)

Заведите таблицу (Google Sheets) с колонками:

| Поле | Зачем |
|---|---|
| Название студии | идентификация |
| Сайт | проверить, какой чат стоит у них самих |
| Город | для персонализации B1 |
| Платформа (Tilda/WP/InSales/…) | угол захода |
| Какой чат ставят (Jivo/Envybox/нет) | крючок «замена Jivo» |
| Контакт: email | цепочка A |
| Контакт: VK / Telegram | дубль-касание |
| Имя ЛПР | персонализация |
| Источник | понять, какой источник даёт партнёров |
| Статус | новый / написал / ответил / тестит / партнёр |
| Дата след. касания | дисциплина follow-up |

## 4. Как использовать парсер VK (`~/vk-parser/vk_parser.py`)

Парсер собирает **активную аудиторию по лайкам/комментам постов** (списки участников у большинства сообществ скрыты).

Применение под партнёрку:
1. Найдите 10–20 **сообществ веб-студий и Tilda/WP-фриланса** в VK (а не конкурентов-чатов — здесь нам нужны студии, а не клиенты).
2. Прогоните парсер по их свежим постам → получите профили активных участников (это практикующие сайтоделы).
3. Отфильтруйте по признакам в профиле/статусе: «веб-студия», «сделаю сайт», «Tilda», «верстка», ссылка на портфолио.
4. Достаньте контакты (сайт из профиля → email/форма; либо ЛС в VK как второе касание).

> Отдельно тем же парсером по сообществам **конкурентов (Jivo/Envybox/Callibri)** собирайте аудиторию для **VK-рекламы** (§8 плана) — это разные списки под разные цели: студии → партнёрка, активные у конкурентов → таргет.

## 5. Порядок работы (неделя 1–2)

1. **День 1–2:** собрать 50 студий вручную из каталогов Tilda + выдачи по 5 крупным городам. Не ждать парсер — начать сразу.
2. **День 2–3:** запустить парсер по VK-сообществам студий, добить список до 150–200.
3. **День 3+:** проверить у каждого, какой чат стоит на их сайте (колонка «какой чат») — это сегментирует заход.
4. **С недели 2:** outreach по цепочке A (см. `cold-emails.md`), 10–15 адресных писем/день + дубль в VK/TG через 2 дня.
5. **Метрика:** не «сколько написал», а **сколько партнёров довели до первой установки**. Цель мес 1 — 3–5 тестируют, мес 2–3 — 10–15 активных.
