# Lemnity «Чат» — рекламный лендинг

Самодостаточный статический лендинг под рекламный трафик (в первую очередь VK-реклама).
Никакой сборки и зависимостей — три файла + ассет. Открывается двойным кликом по `index.html`.

```
landing/chat/
├── index.html      # разметка всех секций
├── styles.css      # дизайн-система (Editorial Light, фирменный синий #1A52DB)
├── script.js       # reveal-анимации, FAQ-аккордеон, плавный скролл, подстановка ссылок
├── assets/
│   └── lemnity.svg  # логотип
└── README.md
```

## Деплой

Любой статический хостинг / поддомен (напр. `chat.lemnity.ru`): залить содержимое папки `chat/`
в корень. CDN/кеш — на усмотрение. Страница лёгкая, грузится мгновенно.

## Мокап в hero

`index.html` → блок `.cw` — **точная статическая копия чат-виджета Lemnity** (макет 1:1 из
`lmntai/components/landing/universal/product-demos.tsx`, `ChatHeroMock`). Фирменный акцент виджета —
`#5951E5` (индиго, как в реальном виджете), отдельно от синего бренда лендинга `#1A52DB`.

Аватары операторов (`assets/avatars/op1–3.jpg`) — **стоковые фото-заглушки** (randomuser.me).
Перед продакшеном заменить на реальные фото команды/операторов или лицензированный сток.

## Опционально

Можно встроить живой боевой виджет чата на сам лендинг как демо — добавить embed-скрипт Lemnity
с реальным `widgetId` перед `</body>`. Не входит в текущую сборку.
